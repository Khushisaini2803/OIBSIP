     PASSWORD GENERATOR PRO
         PROJECT OVERVIEW
 Password Generator Pro is a Python-based application developed as a part of the Oasis Infobyte python Programming Intrenship(OIBSIP).
 This application generates secure and customized passwords using different combinations of letters, numbers, and special characters.

         FEATURES
 > Generates random passwords.
 > Customize password length(4-128 characters).
 > Generate mulitple passwords(up to 20).
 > Include uppercase letters (A-Z).
 > Include lowercase letters(a-z).
 > Includes numbers(0-9).
 > Include special characters(@,#.$,etc.).
 > Password strength indicator.
 > Input validation and error handling.
 > Secure password generation using Python's secrets module.
          TECHNOLOGIES USED
  >Python
  >Secret Module
  >String Module
          REQUIREMENTS
  > Python 3.6 or above
  > Visual Studio Code(or any Python IDE) 
  No additional package installation is required.
          HOW TO RUN
  1. Download or clone this respository.
  2. Open the project folder in VS Code.
  3. Open the terminal.
  4. Run the following command.
     >>Python Khushi_Task2.py
  5. Enter your preferred password length.
  6. Selct the number of passwords.
  7. Choose the character types.
  8. View your generated passwords.

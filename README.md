# BMI Calculator
## About the project
This project is a simple BMI (Body Mass Index)Calculator developed using python as part od the Oasis Infobyte Python Programming Internship.
It calculates BmI using the user's weight and height and displays the corresponding BMI category.
## Features
- Accepts the user's name, weight, and height.
- Calculates BMI and rounds it to two decimal places.
- Displays a BMI category.
- Handles invalid numeric input.
- Rejects zero and negative weight or height.
- Displays a general health screening disclaimer.
## technologies Used
- Python 3
## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the command.
    python Khushi_Task1.py
5. Enter your name, weight in kilograms, and height in meters.
 ## Example
- Name: Khushi
- Weight: 50 kg
- Height: 1.60 m
- BMI: 19.53
- Category: Normal weight
 ## Disclaimer
 BMI is a general screening measure and is not a medical diagnosis.

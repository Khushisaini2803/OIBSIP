🌦️ WEATHERIQ – Smart Weather Intelligence Dashboard

📌 Project Overview

WEATHERIQ is a Python-based smart weather intelligence dashboard developed as part of the Oasis Infobyte Python Programming Internship.

It provides real-time weather information, air quality details, weather forecasts and interactive weather analytics through a modern dashboard.

✨ Key Features

- Live weather search by city.
- Current temperature and feels-like temperature.
- Humidity and wind speed.
- UV index and precipitation information.
- Air Quality Index (AQI).
- PM2.5 and PM10 information.
- 24-hour temperature forecast.
- 7-day weather forecast.
- Interactive temperature graphs.
- Smart weather insights and suggestions.
- Error handling for invalid city names and network issues.

🛠️ Technologies Used

- Python
- Streamlit
- Open-Meteo API
- Requests
- Pandas
- Plotly

⚙️ Installation

Install the required libraries:

pip install streamlit requests pandas plotly

▶️ How to Run

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

python -m streamlit run Khushi_Task3.py

5. Open the local URL displayed in the terminal.
6. Enter a city name and click Get Weather.

🌍 Data Source

Weather and air quality information are provided by Open-Meteo APIs.
